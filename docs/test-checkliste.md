# Test-Checkliste für echte Geräte

Vieles wurde nur im simulierten Browser (Chromium, Playwright) geprüft. Diese Punkte bitte einmal auf dem Handy durchklicken
und Auffälliges melden. Ein Haken pro Punkt reicht.

## Installation und Updates
- [ ] App im Browser öffnen, „Zum Startbildschirm hinzufügen“ bzw. „Installieren“.
- [ ] Nach einem Update erscheint der Hinweis „Update verfügbar“, Antippen lädt die neue Version (Menü zeigt die Versionsnummer).
- [ ] Im Flugmodus startet die App weiterhin und zeigt die Daten.

## Einträge
- [ ] Neuen Service anlegen (mit Kosten, Teilen, Notiz). „Vom letzten Eintrag übernehmen“ füllt die Teile.
- [ ] Foto aufnehmen und als „Beleg“ markieren. Im Eintrag erscheint die Markierung, in der Liste ein Beleg-Symbol.
- [ ] Eintrag bearbeiten und löschen.
- [ ] CSV-Export öffnet sich in Excel/Numbers mit den Spalten „Teile / Material“ und „Notiz“.
- [ ] Druck / „Als PDF speichern“: Deckblatt mit Fahrzeugdaten, Tabelle, Gesamtkosten.

## Erinnerungen und Fristen
- [ ] Einstellungen → Erinnerungen einschalten, Benachrichtigung erlauben.
- [ ] Frist anlegen (Datum in wenigen Tagen): erscheint im Dashboard und löst eine Benachrichtigung aus.
- [ ] „Erledigt“ bei einer jährlichen Frist schiebt das Datum um ein Jahr.
- [ ] Android/Chrome: App schließen und einen Tag warten – kommt die Erinnerung im Hintergrund? (nur installierte App)
- [ ] iPhone: Erinnerungen erscheinen nur beim Öffnen der App. Das ist so gewollt (kein Push-Server).

## Farben
- [ ] VIN eingeben: passende Serienfarben der Baureihe erscheinen. Suchfeld findet auch andere Farben (Name oder Code).
- [ ] „Eigene Farbe wählen“ ändert die Akzentfarbe, Lesbarkeit im hellen und dunklen Design prüfen.

## Google Drive
- [ ] Verbinden, synchronisieren, zweites Gerät: Einträge, Fristen, Notizen und Fotos erscheinen dort.
- [ ] Trennen: Zugriff ist in myaccount.google.com/permissions weg.

## Scheckheft
- [ ] Veröffentlichen, QR-Code mit zweitem Gerät scannen: Seite zeigt Einträge ohne Kosten, Notizen, Teile und Belege.
- [ ] Ablaufdatum auf gestern setzen: Link zeigt „abgelaufen“.
- [ ] „Veröffentlichung beenden“: Link zeigt „existiert nicht mehr“.

## Sicherheitskopie
- [ ] Einen Eintrag anlegen, dann „Alles zurücksetzen“ und unter Einstellungen → Sicherheitskopie wiederherstellen.
